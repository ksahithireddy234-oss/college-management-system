# CampusHub

A campus management web application that puts everything a student or visitor needs in one place.

## Problem it solves
- New visitors struggle to find blocks and buildings
- Venue bookings clash when groups can't see what is already taken
- Notes, rules and event information are scattered

## Features
- **Library:** browse campus library resources
- **Campus Map:** helps newcomers locate blocks and buildings
- **Venue Booking:** check whether a venue is occupied before booking a slot
- **Study Guide (prototype):** assistant interface for student doubts, currently running on mock data
- **Rules & Regulations:** campus rules clearly listed for visitors and new students
- **Clubs & Events:** upcoming clubs and events in one place
- **Notes Upload:** seniors can share notes and PDFs with juniors

## Tech Stack
HTML, CSS, JavaScript

## How to Run
1. Download or clone this repository
2. Open `campushub.html` in any browser
